# 干饭罗盘 🧭

人类三大难题——早上吃啥、中午吃啥、晚上吃啥——的一键终结方案。
纯前端单页应用，双"后端"架构：

- **内容后端 = `data.js`**：餐厅、食堂窗口、菜单数据。改完 `git push`，GitHub Pages 一分钟自动生效。
- **个人后端 = `localStorage`**：吃过记录、心愿单、黑名单、评分，只存本机浏览器，设置页可导出/导入备份。

## 功能（v0.1）

- **每日一推**：用日期做随机种子，当天答案固定，"换一个"最多 5 次（第 6 次按钮劝你接受天意）
- **加权抽签**：心愿单 ×2、👍 ×1.3、👎 ×0.5、本周已吃 n 次 ×1/(1+0.5n)；黑名单永不出现，今天吃过的自动排除
- **天意转盘**：候选铺上转盘等概率摇号，连中 3 次同一店触发"这就是天意"彩蛋
- **四餐段**：早/午/晚自动识别 + 宵夜段（只出还开着的店）；早餐段只推 7:15 前能送到的档位（可开"赌一把"）
- **晚 9 点后**打开早餐页 = "明早吃什么"，附预约单提示
- **奶茶转盘**：专摇 10 家茶饮咖啡
- **记录页**：近 7 天餐数、外卖花费估算、本周之最、流水补记
- **设置页**：心愿单/黑名单管理、自定义选项（小卖部、泡面、自带饭……）、数据导出导入

## 本地使用

双击 `index.html` 即可（data.js 需在同目录）。手机上用 GitHub Pages 访问更方便。

## 部署（GitHub Pages）

```bash
git push                  # 改完数据推上去
```

仓库 Settings → Pages → Branch 选 `main` → Save。
地址：`https://allen546.github.io/ganfan-luopan/`（首次开启约 1 分钟生效）

## 改数据指南（开学补食堂就看这段）

编辑 `data.js`，每个条目字段都有中文注释。**食堂窗口照这个格式加进 `canteen.stalls`**：

```js
{ id: "c1-malatang", name: "一食堂·麻辣香锅窗口", price: 15,
  tags: ["辣","管饱"], menu: ["自选香锅","米饭"],
  days: [1,2,3,4,5] }   // days=周几供应(1=周一)，不写=每天
```

加完把文件顶部 `version` 加 1、`updatedAt` 改成当天，`git push` 完事。

> 小技巧：在浏览器里先开 `index.html` 确认新条目能抽到，再 push。
